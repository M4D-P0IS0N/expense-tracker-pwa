# Regra de Suporte a Múltiplos Temas e Consistência Visual

Sempre que uma nova funcionalidade, componente visual ou estilo for adicionado ou modificado no projeto:

1. **Alteração em Todos os Temas**: A alteração deve obrigatoriamente ser adaptada e refletida em **todos os temas** disponíveis no projeto (ex: Tema Padrão, Schematic, etc.), garantindo consistência visual e funcional.
2. **Perguntar em Caso de Dúvida**: Caso haja qualquer dúvida se uma alteração deve afetar outros temas ou como deve ser adaptada para cada tema, o agente **DEVE perguntar ao usuário antes de executar** a alteração.
